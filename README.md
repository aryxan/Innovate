**JalRakshak 2.0** is a state-of-the-art, government-oriented disaster management and situational awareness platform. Designed for high-performance flood monitoring and administrative coordination, it synchronizes live satellite telemetry with regional geospatial data to provide a "Mission-Ready" safety net for Indian citizens.

---

## 🛠️ Tactical Features

### 📡 High-Fidelity GIS Console
- **Satellite Integration**: Real-time layers from **ISRO Bhuvan** (NRSC) and **IMD Doppler Radar**.
- **Mission-Precise Monitoring**: Exact GPS tracking with custom mission pins for regional surveillance.
- **Atmospheric Flux Tracking**: Live clouds, precipitation, and thermal intensity overlays.

### 🏹 Mission Command Dashboard
- **Regional Telemetry System**: Automated geocoding and safety status calculation based on local river levels.
- **Medical Hub Sync**: Instant identification and location of nearest survival assets (Hospitals & Pharmacies).
- **Tactical Transitions**: Seamless "Mission Sync" boot sequence featuring minimalist Ashoka Chakra scale animations.

### 🌐 Citizen-Centric Intelligence
- **Multi-Lingual Protocol**: Fully operational in Hindi, English, Punjabi, and other regional Indian languages.
- **Voice-Enabled Guidance**: Integrated AI voice assistant for hands-free situational updates.
- **Administrative Response Grid**: Live trackers for local infrastructure repairs and drainage desilting missions.

---

## 🧪 Technology Stack
- **Core**: React 18 / Vite (High-Performance Runtime)
- **Geospatial**: Leaflet / React-Leaflet / OpenStreetMap / GIS layers
- **Motion**: Framer Motion (System Transitions & Chakra Animations)
- **Styling**: Vanilla CSS / Tailwind (Command Center Aesthetic)
- **Icons**: Lucide React (Tactical Iconography)

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (Latest LTS)
- Gemini API Key (for AI Intelligence layers)

### Setup Instructions
1. **Clone & Extract**:
    ```bash
    git clone [repository-url]
    cd JALRAKSHAK2.O-main
    ```

2. **Synchronization**:
    ```bash
    npm install
    ```

3. **Authentication**:
   Create a `.env.local` file in the root directory and set your API key:
   ```env
   VITE_GEMINI_API_KEY=your_gemini_api_key_here
   ```

4. **Launch Mission Hub**:
    ```bash
    npm run dev
    ```
